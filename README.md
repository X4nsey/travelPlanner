Репозиторий проекта: **[https://github.com/X4nsey/travelPlanner.git](https://github.com/X4nsey/travelPlanner.git)**

## 💻 1. Что нужно установить на компьютер перед запуском

Чтобы запустить проект на любом новом компьютере (Windows, macOS или Linux), требуется установить всего **две основные программы**:

### 1.1. Node.js (включает менеджер пакетов npm)
- **Что это:** среда выполнения JavaScript для бэкенда и сборки фронтенда.
- **Требуемая версия:** Node.js **18.18+**, **20 LTS** или **22 LTS** (рекомендуется **Node.js 20** или новее).
- **Где скачать:** официальный сайт **[https://nodejs.org/](https://nodejs.org/)** (выбирайте версию с пометкой **LTS**).
- **Как проверить установку в терминале:**
  ```bash
  node -v
  npm -v
  ```
  *(должны отобразиться номера версий, например `v20.18.0` и `10.8.2`)*.

### 1.2. Git
- **Что это:** система контроля версий для клонирования и обновления проекта.
- **Где скачать:** **[https://git-scm.com/](https://git-scm.com/)**.
- **Как проверить установку в терминале:**
  ```bash
  git --version
  ```

### 1.3. База данных PostgreSQL (на ваш выбор)
Для проекта **не обязательно вручную настраивать сложную базу данных** — предусмотрено 3 варианта:
- **Вариант А (По умолчанию, самый простой — без установки БД):** В проект встроен автоматический `embedded-postgres`. Если на вашем ПК нет запущенного PostgreSQL, бэкенд сам автоматически инициализирует и запустит локальный движок PostgreSQL в папке `backend/.pgdata`. Ничего дополнительно ставить не нужно!
- **Вариант Б (Docker Desktop):** Если у вас установлен **[Docker Desktop](https://www.docker.com/)**, можно запустить PostgreSQL в контейнере одной командой `docker compose up -d`.
- **Вариант В (Локальный PostgreSQL):** Если у вас уже установлен сервис PostgreSQL на компьютере, просто укажите логин и пароль в файле `backend/.env`.

## 🚀 2. Пошаговая инструкция: как запустить сайт с нуля

### Шаг 1. Клонируйте репозиторий с GitHub
Откройте терминал (PowerShell / Командная строка / Git Bash) и выполните:
```bash
git clone https://github.com/X4nsey/travelPlanner.git
cd travelPlanner
```

---

### Шаг 2. Создайте файлы переменных окружения `.env`
Проекту нужны три файла конфигурации: в корне, в папке `backend` и в папке `frontend`. Они создаются на основе готовых примеров `.env.example`:

**В Windows (PowerShell):**
```powershell
Copy-Item .env.example .env -Force
Copy-Item backend\.env.example backend\.env -Force
Copy-Item frontend\.env.example frontend\.env -Force
```

**В Windows (Командная строка CMD):**
```cmd
copy .env.example .env
copy backend\.env.example backend\.env
copy frontend\.env.example frontend\.env
```

**В macOS / Linux (Bash / Zsh):**
```bash
cp .env.example .env
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

> 💡 **Примечание по ключам API:**
> Базовые настройки уже готовы к работе. Если вы захотите включить живую подгрузку новых фотографий с фотобанков, в `backend/.env` можно указать бесплатные ключи `UNSPLASH_ACCESS_KEY` или `PEXELS_API_KEY`. При их отсутствии система использует встроенную курируемую коллекцию фото высокого разрешения.

---

### Шаг 3. Установите все зависимости проекта
В корневой папке проекта выполните одну команду:
```bash
npm run install:all
```
*(Эта команда сама установит все необходимые npm-пакеты и для серверной части `backend`, и для клиентской `frontend`).*

Либо вы можете установить их по отдельности:
```bash
cd backend
npm install

cd ../frontend
npm install
cd ..
```

---

### Шаг 4. Сгенерируйте клиент Prisma и подготовьте таблицы базы данных
Выполните генерацию ORM-клиента и автоматическое создание таблиц в PostgreSQL:
```bash
cd backend
npx prisma generate
npm run db:setup
cd ..
```
*(Скрипт `db:setup` проверит базу данных, применит миграции и создаст таблицы пользователей, поездок, мероприятий и избранных стран).*

---

### Шаг 5. Запустите приложение в двух окнах терминала

#### Окно терминала №1 — Запуск Backend (REST API):
```bash
cd backend
npm run dev
```
Сервер запустится по адресу: **`http://localhost:3000`** *(проверка здоровья API: `http://localhost:3000/api/health`)*.

#### Окно терминала №2 — Запуск Frontend (Vite + Vue 3):
```bash
cd frontend
npm run dev
```
Клиентская часть запустится по адресу: **`http://localhost:5173`**.

---

### Шаг 6. Откройте сайт в браузере
Перейдите по ссылке:
👉 **[http://localhost:5173](http://localhost:5173)**

## 🛠️ 3. Технологический стек

### Frontend
- **Vue 3 (Composition API, `<script setup lang="ts">`)** — современный реактивный интерфейс.
- **TypeScript** — строгая типизация данных.
- **Vite 6** — быстрая сборка, Hot Module Replacement (HMR) и code-splitting.
- **Pinia** — централизованное управление состоянием (пользователь, поездки, каталог стран, избранное, тосты).
- **Vue Router 4** — маршрутизация с защитой приватных разделов (Navigation Guards).
- **Tailwind CSS 3** — адаптивная стилизация, светлая палитра, мобильная верстка.
- **Globe.gl + Three.js** — интерактивный 3D-глобус Земли с океанами, атмосферой, анимацией вращения и интерактивным выбором стран.
- **world-atlas + topojson-client** — локальные географические границы стран без повторных загрузок по сети.
- **Lucide Vue Next** — минималистичные SVG-иконки.
- **Axios** — HTTP-клиент с автоматической передачей HttpOnly cookie и Double-Submit CSRF токенов.
- **VeeValidate 4 + Zod** — валидация форм в реальном времени.

### Backend
- **Node.js + Express** — масштабируемый REST API сервер.
- **TypeScript** — типобезопасный бэкенд код.
- **Prisma ORM** — работа с базой данных, схема моделей и миграции.
- **PostgreSQL** — реляционная СУБД для хранения пользователей, поездок, планов и избранного.
- **Zod** — серверная валидация всех входящих JSON-запросов.
- **bcryptjs** — безопасное хеширование паролей (соль 10 раундов).
- **JWT в HttpOnly Cookie + CSRF Protection** — безопасная аутентификация без хранения токенов в `localStorage` (защита от XSS и CSRF).
- **embedded-postgres** — встроенный резервный сервер БД для запуска на любой машине без предварительной установки Postgres.

## 🌟 5. Функционал и возможности приложения

### 1. Главная страница («Вдохновение для поездок»)
- Демонстрационные готовые маршруты (Санкт-Петербург, Стамбул, Рим, Алтай, Токио, Париж) с фотографиями высокого разрешения.
- **Двойное отображение цен:** для зарубежных поездок с ценами в USD или EUR рядом в скобках автоматически рассчитывается эквивалент в рублях (например, `1 200 $ (~110 400 ₽)`).
- **Интерактивное модальное окно по клику на карточку:** открывает подробное описание маршрута, ключевые достопримечательности, лучший сезон для посещения, пример программы по дням и кнопку *«Запланировать такую поездку»* (автоматически подставляет параметры в форму создания поездки).

### 2. Интерактивный 3D-глобус («Исследовать мир» — `/explore`)
- Трёхмерная модель Земли на базе WebGL/Three.js с океанами, границами континентов и атмосферой.
- Возможность свободного вращения, приближения, отдаления и включения авто-вращения.
- **Подсветка стран:** 
  - Янтарный цвет — выбранная страна (физически приподнимается над поверхностью).
  - Бирюзовый цвет — страна под курсором мыши.
  - Мятный цвет — страны с готовыми авторскими путеводителями в каталоге.
  - Серый цвет — все остальные страны мира (также доступны для выбора и создания маршрута).
- Боковая карточка страны: столица, флаг, фото, континент, население, площадь, валюта, языки и популярные города.
- Кнопка *«Выбрать на глобусе»* при создании поездки: сохраняет введённые вами данные, позволяет ткнуть в нужную страну на глобусе и возвращает вас обратно в форму.

### 3. Каталог стран мира («Страны мира» — `/countries` и `/countries/:slug`)
- Сетка карточек с фото, столицами и флагами.
- Поиск по названию страны или столице.
- Фильтры по 6 континентам (Европа, Азия, Африка, Северная Америка, Южная Америка, Океания) и сортировка по алфавиту.
- **Детальная страница страны:** фотогалерея по категориям (*Города, Природа, Архитектура, Туристические места*) с полноэкранным просмотром (lightbox), популярные города, достопримечательности, часовой пояс и валюта.

### 4. Избранные страны (`/favorites`)
- Кнопка-сердечко на карточках стран и на странице глобуса.
- Избранное надёжно сохраняется в PostgreSQL в привязке к вашему аккаунту и синхронизируется между сессиями.

### 5. Управление поездками и планирование по дням (`/trips`)
- Создание поездок с расчётом дат, бюджета и количества участников.
- Автоматический расчёт длительности поездки в календарных днях.
- Интерактивный селектор страны с быстрым выбором популярных городов.
- **План поездки по дням:** автоматическая генерация вкладок для каждого календарного дня поездки.
- Добавление мероприятий (экскурсии, переезды, отели, рестораны) с временем начала и окончания, адресом, заметками и стоимостью.
- Автоматическая сортировка событий каждого дня в строгом хронологическом порядке.

### 6. Безопасность и личный профиль (`/profile`)
- Регистрация и авторизация по защищённым HttpOnly cookie.
- Двойная защита от CSRF-атак.
- Редактирование имени и смена пароля с проверкой текущего пароля.
- Изоляция данных: каждый пользователь имеет доступ только к своим собственным поездкам.

## 🔧 7. Решение частых проблем (Troubleshooting)

1. **Порт 3000 или 5173 уже занят:**
   - Если сервер сообщает `EADDRINUSE: address already in use`, закройте предыдущие запущенные терминалы Node.js или завершите зависший процесс в диспетчере задач.
2. **В браузере не обновляются стили или 3D-глобус:**
   - Перезапустите фронтенд с очисткой кэша:
     ```bash
     cd frontend
     npm run dev -- --force
     ```
   - В браузере нажмите сочетание клавиш **`Ctrl + F5`** (жёсткая перезагрузка страницы без кэша).
3. **Ошибка подключения к базе данных (`P1001`):**
   - Убедитесь, что в `backend/.env` включен параметр `USE_EMBEDDED_PG_FALLBACK=true` (если у вас нет внешнего PostgreSQL). При первом запуске встроенная база инициализируется за несколько секунд в папке `backend/.pgdata`.
